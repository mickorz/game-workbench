## 设计取舍

- 键盘漫游只做「箭头移焦点」，不做「箭头即选中」：现有交互是「选中即自动跳下一题」（`choose()`），箭头一按就跳题会失控；thinkrail 的「箭头选中 + Enter 确认」模式留给 P2（若 P2 引入显式 Submit 按钮则一并切换）
- 旧 header 的「跳过全部 X」按钮移除（footer 已有 Skip，重复）
- `questionnaire.previous/next/position/skipAll` locale key 保留未删（低风险，避免牵动其他引用排查）
