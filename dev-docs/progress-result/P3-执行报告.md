## 过程中发现并根治（补丁 4）

- 症状：角标永远「未连接」，console 报 CSP 违规。
- 根因（双重）：① 宿主 CSP `connect-src` 只放行 `http://127.0.0.1:*`，不放行 `localhost`；② 桥的 HttpListener `localhost` 前缀仅绑 IPv6 `[::1]`，`127.0.0.1` 直连被拒。
- 修复：桥 `startServer()` 补加 `http://127.0.0.1:<port>/` 前缀（实测免管理员）；渲染层探活固定用 `127.0.0.1`。已同步打进 `plugins/fairygui/editor-plugin/main.js` 与 dev-examples 工程副本，NOTICE 补丁清单更新为四条。
