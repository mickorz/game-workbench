## 关键设计决策

- **全量快照式而非增量操作**：`todo_write` 每次重写整张清单（同 thinkrail pi-todos），协议最简、无合并冲突；同 turnId 固定 id `{turnId}:todos`，后写覆盖
- **沿用 `update_plan → plan` 拦截先例**：daemon 把 `todo_write` 转成 `todoList` ThreadItem 而非普通工具调用展示；实时经 Manager `#updateItem` 发布事件，历史重建从 arguments 解析（不依赖 toolResult details）
- **ThreadItem 不带 status**：快照式清单的「状态」在条目里（每项 pending/in_progress/done），item 本身无生命周期，同 plan item；turn 结束时无需补完成态
- **渲染走 messages 通道**：completed turn 中 todoList 不是 work item，自然落到消息流里持久可见；active turn 中作为 work item 实时刷新
