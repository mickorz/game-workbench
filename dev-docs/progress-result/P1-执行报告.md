## 过程中发现并根治的问题

- **桥长时间挂起复现**（P0 遗留）：编辑器空闲后 onUpdate 停跑，TCP 通但命令不执行。根因 = `runInBackground` 被编辑器反复覆盖而 agent-bridge 只设一次（与 FairyGUI-MCP 注释一致）。补丁：`onUpdate()` 每帧重设，重启后未再复现。经验文档已更新。
