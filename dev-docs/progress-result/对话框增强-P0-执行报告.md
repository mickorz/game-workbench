## 行为翻转说明（重要）

旧版把「不显示 thinking」钉进了测试（如 `does not keep completed Pi thinking as a history row`、`hides streamed reasoning text behind the generic Thinking state`）——这是本阶段要翻转的刻意产品决策（用户明确要求详细 thinking 内容显示）。共更新 14 个用例断言并重命名以描述新行为。同时 `tool-group-summary-thinking` 特殊态删除（思考块独立承载），`Stopped while thinking` 兜底文案仅在 work 为空时出现（有思考块时由块本身表达）。

## 手动验证步骤（待用户确认）

1. `bun run dev` 起开发态，打开任一会话
2. 发送一条需要思考的消息：观察思考块实时展开、内容流式追加
3. 工具调用开始后回看思考块（仍在原位、收起为标题行）
4. 会话完成后：`工作了 Xs` 折叠区内出现收起的思考块，点击展开看全文
5. 切走再切回会话：手动设定的展开/收起状态保持
