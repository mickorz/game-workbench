## 关键设计决策

- **reconcile 只做三个最小规则**：同组同名旧 done 保持 done、旧 origin=user 身份保持、未被新快照收录的用户条目原样追加；不做 in_progress 恢复、不做模糊匹配（thinkrail 的 flattenTitle 归一化未引入——我们的 title 由 schema 约束同一来源，先观察）
- **addUserTodo 同标题去重**：无组同名条目已存在则只更新快照不重复追加、也不再 steer（避免重复 nudge 噪音）
- **加 todo 入口仅活动 turn 的卡显示**：`TodoActionsContext { turnId, add }`（仿 WorkspaceLinkContext），卡片比对 `item.turnId`，避免旧 turn 卡上加新 todo 落到别的 turn 的错位；TurnArticle memo 不受影响
- **nudge 走 session.steer**：注入到运行中的 turn（与队列 steer 同通道），历史重建后该消息由 turn-display 前缀过滤隐藏
