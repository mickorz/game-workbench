## 关键设计决策

- **多选 value 传输格式**：沿用单选的 `value: string`（换行拼接选中项），提交协议形状不变——daemon/renderer 同读同写，contracts 注释写死格式，避免引入 `string[]` 破坏 `AnswerQuestionnaireRequest` 现有消费者
- **多选不自动提交**：toggle 不触发 `choose()`（自动跳题流），改由显式 Submit 按钮（仅当存在多选题且全部答完时出现）；单选保持原有「选中即跳题、答完自动提交」
- **preview 用 `<pre>` 纯文本**：P2 不引入 markdown 渲染依赖，升级路径是接 `MarkdownContent`（仓库已有组件）
