# PSD 素材库使用与维护说明

本目录是 FGUI 美术自动化流程的**可复用源 PSD 素材库**。
在业务流程运行阶段（s4 `/s4-psd`），系统**仅对本库进行只读检索与消费**，绝不在此过程中修改原件或重新扫描。

---

## 一、目录结构规范

```text
.opencode/PSD素材库/
├─ index.json            ← 素材库全局索引（由 build_index.py 维护）
├─ build_index.py        ← 本地维护脚本（美术添加新 PSD 后独立运行）
├─ README.md             ← 本说明文档
├─ 按钮/                 ← 分类：各类按钮源文件
│  ├─ 按钮.psd
│  └─ _预览/              ← 按钮分类独享缩略图目录（自动生成）
├─ 标签/                 ← 分类：各类角标、文本标签源文件
│  ├─ 标签.psd
│  └─ _预览/              ← 标签分类独享缩略图目录
├─ 文字/                 ← 分类：各类花字、标题文字源文件
│  ├─ 文字.psd
│  └─ _预览/              ← 文字分类独享缩略图目录
└─ _原稿/                ← 未整理 / 暂存区（索引脚本会自动跳过此目录）
```

---

## 二、素材库运维操作流程（仅美术离线维护时使用）

当有新的通用美术源文件需要纳入素材库供以后需求复用时，请按以下步骤操作：

### 1. 规范图层组结构
- **最外层组（制作单元）**：代表完整组件（如一个按钮）。
- **嵌套子组（底图组）**：代表纯背景/形状底图（包含圆角矩形、光效等）。
- 确保最外层组名尽量清晰（如 `按钮-蓝`、`标签-自摸`）。

### 2. 放入对应分类文件夹
- 将新 PSD 放入 `按钮/`、`标签/` 或 `文字/` 目录下（如果尚未整理好，可先放在 `_原稿/`）。

### 3. 运行维护脚本刷新索引与缩略图
在终端中进入本目录直接运行：

```powershell
python build_index.py --write --preview
```

该命令会自动：
1. 解析所有 PSD 的制作单元层级与嵌套底图结构；
2. 调起本机 PhotoCraft，在对应分类的 `_预览/` 目录下导出最外层单元的透明裁剪缩略图；
3. 刷新并落盘 `index.json`。

## 三、业务需求流水线（s4）的只读消费边界

- **运行态只读**：运行 `/s4-psd` 命令时，流程工具通过 `workspace.py find-asset` 纯只读检索 `index.json` 和对应的 `_预览/` 图。
- **绝不原地修改**：命中复用素材后，流程会自动将目标 PSD 拷贝到当前需求的私有工作目录（`.opencode/work/.../psd/制作/`）中进行改字改色，本素材库中的任何原件和索引均保持**完全只读、不受影响**。
