# 07 · 打包与迁移

目标：把流程包交给另一台机器 / 另一个人，对方解压后能独立跑起来，且**不带走你的本机路径、token、需求产物和密钥**。

## 1. 包里必须有什么

| 内容 | 是否必需 | 说明 |
|---|---|---|
| `.opencode/agent/` | ✅ | `fgui-flow` 主 agent |
| `.opencode/command/` | ✅ | `/s0-env` ~ `/s4-psd` |
| `.opencode/skills/` | ✅ | 5 个技能 + 脚本 |
| `.opencode/lib/` | ✅ | `workspace.py`、`photocraft.py` |
| `.opencode/knowledge/` | ✅ | 动态知识库 |
| `docs/` | ✅ | 本套文档 + 示例配置 + 打包脚本 |
| `.opencode/xc_spce_info.json` | ✅ | s0 定位 client 工程的依据 |
| `.opencode/workspace.example.json` | ✅ | 配置模板 |
| `.opencode/photocraft.example.json` | ✅ | PhotoCraft 客户端配置模板 |
| `AGENTS.md`（工作区根） | ✅ | opencode 会话级硬规矩；**不能只拷 `.opencode`** |
| `.opencode/PSD素材库/` | 建议 | s4 复用源 PSD；可整包分享 |
| 项目级 `opencode.json` | 可选 | 如果用了项目级 MCP 配置，放工作区根；**不要带 API Key** |

## 2. 包里不要有什么

| 内容 | 原因 |
|---|---|
| `.opencode/work/` | 你的需求产物、事实底座、测试数据；体积大且含项目信息 |
| `.opencode/inbox/` | 需求 Excel，可能含未公开内容 |
| `.opencode/workspace.json` | 本机绝对路径，换机器会指错 |
| `.opencode/photocraft.json` | 本机 exe / token / 读写根路径 |
| `.opencode/node_modules/` | 体积大，且非运行必需；需要时再 `npm install` |
| `.opencode/__pycache__/`、`*.pyc` | Python 缓存 |
| `package-lock.json` / `bun.lock` | 本机依赖锁定文件，按需再生成 |
| token 文件（`.photocraft-control.token`） | 安全凭证，绝不能交付 |
| `opencode.json` 里的 `apiKey` | 模型供应商密钥 |
| `dist/`、`_tmp/`、测试 PSD、根目录测试 Excel | 临时/个人文件 |
| `.git/` | 版本库元数据，按需另发 |

## 3. 一键打包（推荐）

脚本：`docs/tools/pack_release.ps1`

### 3.1 默认打包

```powershell
powershell -ExecutionPolicy Bypass -File docs/tools/pack_release.ps1
```

默认行为：

- 输出到 `<工作区根>/dist/FGUI-ArtFlow_<时间戳>/`；
- 同时生成同名 `.zip`；
- 包含 `.opencode`（排除 work / inbox / node_modules / 缓存 / 本机配置）；
- 包含 `docs/`（说明文档中心、MCP示例配置、打包工具）；
- 包含 `AGENTS.md`；
- 包含 `PSD素材库/`；
- 生成 `PACKAGE-INFO.txt`（打包时间、来源、包含/排除说明）；
- 生成 `先看这里.txt`。

> 如果你用了**项目级 `opencode.json`**（MCP 配置），脚本不会自动复制它，避免把 API Key 带出去。需要随包交付时，手动复制到包根，并确认里面只有 MCP 配置、没有密钥。

### 3.2 常用参数

```powershell
# 指定输出目录
powershell -ExecutionPolicy Bypass -File docs/tools/pack_release.ps1 `
  -OutDir "D:\交付\FGUI-ArtFlow-v1"

# 连某个需求的 work 产物一起带（默认不带）
powershell -ExecutionPolicy Bypass -File docs/tools/pack_release.ps1 -IncludeWork

# 连 inbox 一起带（一般不要）
powershell -ExecutionPolicy Bypass -File docs/tools/pack_release.ps1 -IncludeInbox

# 不带素材库（对方自己准备）
powershell -ExecutionPolicy Bypass -File docs/tools/pack_release.ps1 -SkipLibrary

# 只出目录，不压缩
powershell -ExecutionPolicy Bypass -File docs/tools/pack_release.ps1 -SkipZip

# 覆盖已存在的输出
powershell -ExecutionPolicy Bypass -File docs/tools/pack_release.ps1 -Force
```

### 3.3 打包后自检

```powershell
# 看目录
Get-ChildItem "<输出目录>" -Force

# 确认没有本机配置 / 缓存 / token
Get-ChildItem "<输出目录>" -Recurse -Force |
  Where-Object { $_.Name -in @('workspace.json','photocraft.json','__pycache__','node_modules') }
```

## 4. 手工打包（不想用脚本时）

在工作区根执行：

```powershell
$pkg = "dist\FGUI-ArtFlow-manual"
New-Item -ItemType Directory -Force $pkg | Out-Null

robocopy ".opencode" "$pkg\.opencode" /E `
  /XD work inbox node_modules __pycache__ .git `
  /XF workspace.json photocraft.json .gitignore package.json package-lock.json bun.lock *.pyc `
  /NFL /NDL /NJH /NJS /NP

robocopy "docs" "$pkg\docs" /E /NFL /NDL /NJH /NJS /NP
Copy-Item "AGENTS.md" "$pkg\AGENTS.md"

$items = Get-ChildItem -LiteralPath $pkg -Force | Select-Object -ExpandProperty FullName
Compress-Archive -LiteralPath $items -DestinationPath "$pkg.zip" -Force
```

> 不要用 `Compress-Archive -Path "$pkg\*"`：`*` 可能漏掉以点开头的 `.opencode` 目录。

> `robocopy` 退出码 `0~7` 都算成功（`1` 表示复制了文件，不是错误）；`8+` 才是失败。

手工打包后，按第 3.3 节自检。

## 5. 交付前清理与脱敏

### 5.1 必查

- [ ] 包内没有 `workspace.json`；
- [ ] 包内没有 `photocraft.json`；
- [ ] 包内没有 `.photocraft-control.token`；
- [ ] 包内没有 `node_modules/`、`__pycache__/`、`*.pyc`；
- [ ] 包内没有 `work/`、`inbox/`（除非有意带上）；
- [ ] 包内没有真实 `apiKey` / `sk-...`；
- [ ] `xc_spce_info.json` 里的路径是接收方能理解的，或已改成占位；
- [ ] 文档里的示例路径已改成占位或通用路径；
- [ ] zip 解压后，`docs/README.md` 能打开。

### 5.2 敏感信息扫描

```powershell
# 粗略扫描密钥/本机路径（按需调整）
rg -n "sk-[A-Za-z0-9]|apiKey|control-token|D:\\\\" .opencode
```

发现后再决定：删除、改成占位、或确认可公开。

### 5.3 `xc_spce_info.json` 怎么处理

如果是**同一项目内部交接**：保留真实 `client_code_root` / `game_id` / `game_key`，对方可直接 s0。

如果是**跨项目/对外模板**：把值改成占位，让对方自己填，或让对方跳过自动定位：

```powershell
python .opencode/lib/workspace.py env --client "<对方的真实工程目录>"
```

## 6. 接收方验收清单

### 6.1 解压与放置

- [ ] 解压到**工作区根**（含 `.opencode` 的那层）；
- [ ] `AGENTS.md`、`docs/` 与 `.opencode/` 在同一级；
- [ ] 真实 client 工程可以在任意位置，不需要放进工作区根。

### 6.2 环境

- [ ] `python --version` ≥ 3.10；
- [ ] `python -c "import PIL, openpyxl"` 通过；
- [ ] opencode 能启动；
- [ ] 模型供应商已配置（自己的 key）。

### 6.3 工程定位

```powershell
python .opencode/lib/workspace.py env --check
python .opencode/lib/workspace.py env --client "<真实工程目录>"
python .opencode/lib/workspace.py where
```

- [ ] `client_dir` 存在；
- [ ] 目录下有 `assets/`、`settings/`、`*.fairy`；
- [ ] `assets/` 下有 `game_key` 前缀包。

### 6.4 PhotoCraft

```powershell
Copy-Item .opencode/photocraft.example.json .opencode/photocraft.json
# 编辑 exe / port / token_file / read_root / write_root
python .opencode/lib/photocraft.py --check
```

- [ ] `✓ 已连接`；
- [ ] 读写根覆盖 client 工程、素材库、需求输出；
- [ ] MCP 配置（如需要）已改路径并重启 opencode。

### 6.5 流程冒烟

```powershell
python .opencode/skills/fgui-flow/scripts/scan_fgui.py
python .opencode/skills/fgui-flow/scripts/lookup.py --check
python .opencode/skills/fgui-flow/scripts/knowledge.py --list
```

- [ ] 事实底座生成；
- [ ] `lookup --check` 不报过期；
- [ ] 知识库能列出文件与标题；
- [ ] opencode 里能看到 `/s0-env` ~ `/s4-psd`；
- [ ] agent 列表里有 `fgui-flow`。

### 6.6 第一条需求

建议先用一个小需求跑通：

```
/s0-env → /s1-req → /s2-fgui（看效果）→ /s3-to-psd → /s4-psd
```

- [ ] s1 产出 `清单.json` 的 `需求[]` 非空；
- [ ] s2 能改到 client 工程、能建快照；
- [ ] s3 能出 PSD；
- [ ] s4 能导出 PNG 并 `place` 回写。

## 7. 发包方最终检查

- [ ] 文档已同步（命令/脚本/配置有变化时改 `03`、`04`、`06`）；
- [ ] 示例配置里的路径是占位或通用路径；
- [ ] `PACKAGE-INFO.txt` 已生成；
- [ ] zip 能正常解压；
- [ ] 在干净目录试跑过 `workspace.py where` 和 `knowledge.py --list`；
- [ ] 记录了版本号 / 日期 / 变更摘要（可写在 `PACKAGE-INFO.txt` 或交付说明里）。

## 8. 迁移到另一台机器的最小步骤

```
1. 解压到工作区根
2. pip install pillow openpyxl
3. 配 opencode 模型供应商
4. workspace.py env --client <工程目录>
5. 复制 photocraft.example.json → photocraft.json 并改路径
6. photocraft.py --check
7. 配 opencode MCP（可选）
8. scan_fgui.py → lookup.py --check → knowledge.py --list
9. /s1-req 开始
```

如果对方只需要 s0~s2（不出 PSD、不切图），可以跳过 PhotoCraft 和 MCP，只保留 Python + opencode。
