# 02 · 安装与首次配置

## 1. 前置条件

| 项 | 要求 | 用途 |
|---|---|---|
| 操作系统 | Windows 10/11 | 脚本按 PowerShell 5.1 编写 |
| Python | 3.10+，`python` 在 PATH | 所有脚本 |
| opencode | 能正常启动、能加载项目级 `.opencode/` | 命令 / agent / 技能宿主 |
| Pillow | `python -m pip install pillow` | 参考图适配、PSD 预览、读图片尺寸、导出校验 |
| openpyxl | `python -m pip install openpyxl` | s1 读 Excel |
| PhotoCraft 桌面端 | 可选，s3/s4 必需 | 搭 PSD、导出切图 |
| PSD 素材库 | 可选 | s4 复用源 PSD；没有就全走占位 |

一次装齐：

```powershell
python --version
python -m pip install pillow openpyxl
```

## 2. 目录怎么摆

接收方的工作区应该是这样：

```
<工作区根>\
├─ AGENTS.md                    ← 必须带，opencode 每次会话自动加载
├─ docs\                        ← 本套使用说明文档
├─ .opencode\                   ← 本流程包
│  ├─ agent\ command\ skills\ lib\ knowledge\
│  ├─ xc_spce_info.json         ← 程序配置（定位 client 工程用）
│  ├─ workspace.example.json    ← workspace.json 模板
│  ├─ photocraft.example.json   ← PhotoCraft 客户端配置模板
│  ├─ workspace.json            ← s0 生成，不要从别人机器直接拷
│  └─ PSD素材库\                 ← 可选
└─ .xflow\...\<game_id>\        ← 真实 client 工程（位置可变）
```

要点：

- **必须在「含 `.opencode` 的那层」启动 opencode**，否则斜杠命令和 agent 可能加载不到。
- `.opencode` 与 `AGENTS.md` 是配套的：只拷 `.opencode` 不带 `AGENTS.md`，会话级硬规矩会缺失。
- client 工程**不必**在工作区根下面固定的位置；由 s0 定位，写进 `workspace.json` 的 `client_dir`。

## 3. 首次配置（按顺序）

### 3.1 确认 Python 与依赖

```powershell
python --version
python -c "import PIL, openpyxl; print('deps ok')"
```

### 3.2 准备 `xc_spce_info.json`

这个文件决定 s0 怎么自动找工程。最少关注三个字段：

```json
{
  "project_info": {
    "client_code_root": ".xflow/xc/xcodeDev/game-mahjong/client"
  },
  "game_info": {
    "game_id": "42324",
    "game_key": "boxKaWuXing"
  }
}
```

- `client_code_root`：相对**工作区根**的 client 代码目录。
- `game_id`：该目录下真实工程目录名。
- `game_key`：`assets/` 下包名前缀（如 `boxKaWuXing_*`）。

不确定或本机没有 `.xflow` 时，不用改这个文件，直接用 `env --client` 指定真实工程目录（见 3.3）。

### 3.3 跑 s0 定位工程

```powershell
# 只看，不写文件
python .opencode/lib/workspace.py env --check

# 自动定位并写入 .opencode/workspace.json
python .opencode/lib/workspace.py env

# 自动定位失败时，显式指定真实 FGUI 工程根
python .opencode/lib/workspace.py env --client "D:\path\to\client\42324"

# 确认结果
python .opencode/lib/workspace.py where
```

成功的标志：`where` 打印的 `client_dir` 存在，且该目录下能看到 `assets/`、`settings/`、`*.fairy`。

生成的 `workspace.json` 形如：

```json
{
  "out_root": ".opencode\\work",
  "素材库根": ".opencode\\PSD素材库",
  "工程快照范围": "packages",
  "client_dir": ".xflow\\xc\\xcodeDev\\game-mahjong\\client\\42324",
  "game_key": "boxKaWuXing",
  "game_id": "42324"
}
```

字段说明：

| 字段 | 说明 |
|---|---|
| `out_root` | 工作层输出根，默认 `.opencode\work`，相对工作区根 |
| `素材库根` | PSD 素材库位置，可指向工程外 |
| `工程快照范围` | `packages`＝只快照本轮包（推荐）；`all`＝整个 `assets/` |
| `client_dir` | 真实 FGUI 工程根 |
| `game_key` / `game_id` | 需求目录与包名前缀用 |

### 3.4 配置 PhotoCraft（s3/s4）

按 `06-PhotoCraft与MCP配置.md` 做三件事：

1. 确认 `photocraft.exe` / `photocraft-cli.exe` 位置。
2. 启动桌面端（带 `--control`、token 文件、读写根）。
3. 配 opencode MCP + `.opencode/photocraft.json`（Python 客户端）。

快速自检：

```powershell
python .opencode/lib/photocraft.py --check
```

看到 `✓ 已连接` 即可。第一次运行会自动拉起 PhotoCraft 桌面端。

### 3.5 准备 PSD 素材库（可选）

没有素材库也能跑，s4 会全部走占位/AI 生图。要启用：

```powershell
# 素材库目录结构见 05-知识库与素材库.md
python .opencode/skills/psd-style/scripts/build_index.py `
  --lib ".opencode/PSD素材库" --write --preview
```

并在 `workspace.json` 的 `素材库根` 指向它。

### 3.6 启动 opencode

1. 在**工作区根**启动 opencode。
2. 确认斜杠命令能看到 `/s0-env`、`/s1-req`、`/s2-fgui`、`/s3-to-psd`、`/s4-psd`。
3. 确认 agent 列表里有 `fgui-flow`。
4. **配置类文件改过之后要重启 opencode**（`workspace.json`、`opencode.json`、命令/技能文件都算）。

### 3.7 首次冒烟测试

```powershell
# 1) 路径是否正确
python .opencode/lib/workspace.py where --需求 测试

# 2) 事实底座是否可用（第一次必须扫一次；之后工程改过再扫）
python .opencode/skills/fgui-flow/scripts/scan_fgui.py
python .opencode/skills/fgui-flow/scripts/lookup.py --check

# 3) 知识库是否可读
python .opencode/skills/fgui-flow/scripts/knowledge.py --list

# 4) PhotoCraft 是否可用
python .opencode/lib/photocraft.py --check
```

四项都通过，就可以从 `/s1-req` 或 `/s0-env` 开始跑真实需求。

## 4. 模型接入（opencode 层）

本流程包**不包含**模型供应商配置。opencode 的供应商配置通常在用户级 `~/.config/opencode/opencode.json`，里面可能有 API Key，**不要随包分发**。

接收方按自己的环境配置一个 OpenAI 兼容供应商即可，示意（把占位符换成自己的）：

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "your-gateway": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Your Gateway",
      "options": {
        "baseURL": "https://your-gateway.example.com/v1",
        "apiKey": "YOUR_KEY"
      }
    }
  }
}
```

建议：

- API Key 用环境变量或本机 `opencode auth` 管理，不要写进交付包。
- 命令 / agent / 技能会消耗较多上下文，选支持长上下文的模型。
- 如果 MCP 工具有长任务，配 `"experimental": { "mcp_timeout": 60000 }`（见 06）。

## 5. 常见首次配置失败

| 现象 | 原因 | 处理 |
|---|---|---|
| 斜杠命令不出现 | 不在工作区根启动；或没重启 | 在含 `.opencode` 的目录启动；重启 opencode |
| `env --check` 报 client_code_root 不存在 | 本机没有 `.xflow` | 用 `env --client <真实工程目录>` |
| `where` 没有 `client_dir` | 还没跑 s0 | 先 `workspace.py env` |
| `scan_fgui.py` 找不到工程 | `client_dir` 指向错误 | 重新 s0；或 `scan_fgui.py --root <工程根>` |
| `photocraft.py --check` 失败 | 桌面端 / token / 端口问题 | 看 06 的排查表 |
| `import openpyxl` 失败 | 没装依赖 | `python -m pip install openpyxl` |
| 中文显示乱码 | 控制台编码 | 文件本身是 UTF-8；用编辑器看，或先 `chcp 65001` |

更多问题见 `08-常见问题.md`。
